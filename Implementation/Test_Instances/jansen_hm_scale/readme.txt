HM SCALING (directory jansen_hm_scale, called "HM-Skalierung" in the thesis,
Section 5.2.1 and 5.2.6). Generated by generate.py.

Varies only the number of jobs n and keeps everything else fixed, so that only
the multiplicities u_i grow: n/m = 8 is fixed, hence the capacities MULTIFIT
tests (C ~ sum p / m + p_max) stay constant along the n axis.

PARAMETERS
  d        : 3, 4
  scenario : dense, mixed, asymmetric (size ranges as in jansen_hm)
  n        : 40, 400, 4000, 40000   (m = n / 8)
  seeds    : 5 per combination (deterministic, MD5-based)
  total    : 2 * 3 * 4 * 5 = 120

Size combinations whose saturated configuration count prod_i (floor(C/p_i) + 1)
exceeds Q_BUDGET = 200000 are redrawn (see generate.py). Every size gets at
least one job.

FORMAT
  line 1: m, line 2: n, line 3: p[1] ... p[n] (shuffled)
FILE NAME: HMS_<scenario>_d<D>_n<NNNNNN>_m<MMMMM>_<K>.txt

OPT
  opt_known_gg.txt / opt_certified.csv: certified optimal makespans of all
  120 instances, computed by ../jansen_hm/solve_opt_gg.py --dir jansen_hm_scale.
